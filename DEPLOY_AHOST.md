# Инструкция по деплою бота на ahost.uz

## Подготовка проекта

1. Убедитесь, что все файлы проекта загружены на хостинг через FTP или файловый менеджер cPanel.

2. Структура файлов должна быть следующей:
   ```
   ваша_папка/
   ├── app.py
   ├── bot.py
   ├── config.py
   ├── database.py
   ├── passenger_wsgi.py
   ├── requirements.txt
   ├── templates/
   │   ├── login.html
   │   └── users.html
   └── audios/
       ├── Rus tili/
       └── Ingliz tili/
   ```

## Настройка в cPanel

### 1. Создание Python приложения

1. Войдите в **cPanel** вашего хостинга ahost.uz
2. Найдите раздел **"Настройка Python приложений"** (Python App)
3. Нажмите **"+ создать новое приложение"**

### 2. Настройка приложения

Заполните форму:
- **Версия Python**: выберите `Python 3.11` или `Python 3.12` (рекомендуется 3.11)
- **Корневой каталог приложения**: укажите путь к папке с проектом (например, `/home/username/edulingo`)
- **URL приложения**: выберите домен или поддомен (например, `bot.yourdomain.uz`)
- **Файл логов Passenger**: укажите путь к файлу логов (например, `/home/username/edulingo/passenger.log`)

4. Нажмите **"+Создать"**

### 3. Установка зависимостей

После создания приложения:

1. Скопируйте команду для входа в виртуальное окружение (она будет показана в интерфейсе)
2. Откройте **Терминал** в cPanel или подключитесь по SSH
3. Выполните команду для входа в виртуальное окружение
4. Установите зависимости:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

   Или установите вручную:
   ```bash
   pip install python-telegram-bot==21.0
   pip install python-dotenv==1.0.0
   pip install aiosqlite==0.19.0
   pip install Flask==3.0.3
   pip install python-dateutil==2.9.0.post0
   pip install openpyxl==3.1.2
   ```

### 4. Настройка переменных окружения

В cPanel в разделе **"Настройка Python приложений"** найдите ваше приложение и добавьте переменные окружения:

- `BOT_TOKEN` - токен вашего бота от BotFather
- `BOOK_WEBSITE_URL` - URL сайта с книгой (опционально)
- `ADMIN_USERNAME` - имя пользователя для админ-панели
- `ADMIN_PASSWORD` - пароль для админ-панели
- `SECRET_KEY` - секретный ключ для Flask (можно сгенерировать случайную строку)
- `WEBHOOK_URL` - полный URL вашего приложения (например, `https://bot.yourdomain.uz`)
- `DATABASE_PATH` - путь к файлу базы данных (например, `edulingo.db`)
- `CHANNEL_USERNAME` - username канала для обязательной подписки (например, `@edulingo_channel`)
- `FLASK_ENV` - установите `production`

### 5. Перезапуск приложения

После настройки переменных окружения:
1. Нажмите кнопку **"Перезапустить"** в интерфейсе управления приложением
2. Дождитесь завершения перезапуска

## Установка Webhook

После успешного деплоя:

1. Откройте в браузере URL вашего приложения: `https://bot.yourdomain.uz/setup-webhook`
2. Должен появиться JSON ответ с сообщением об успешной установке webhook
3. Проверьте статус webhook: `https://bot.yourdomain.uz/webhook/status`

## Проверка работы

1. **Проверка webhook**: откройте `https://bot.yourdomain.uz/webhook/status` - должен вернуться JSON с информацией о webhook
2. **Проверка админ-панели**: откройте `https://bot.yourdomain.uz/admin/users` - должна открыться страница входа
3. **Проверка бота**: отправьте команду `/start` боту в Telegram

## Решение проблем

### Бот не отвечает

1. Проверьте логи в файле, указанном в "Файл логов Passenger"
2. Проверьте, что webhook установлен: `https://bot.yourdomain.uz/webhook/status`
3. Убедитесь, что переменная `WEBHOOK_URL` указана правильно (без `/webhook` в конце)
4. Попробуйте переустановить webhook: `https://bot.yourdomain.uz/setup-webhook`

### Ошибки в логах

1. Откройте файл логов, указанный в настройках приложения
2. Проверьте наличие ошибок импорта или инициализации
3. Убедитесь, что все зависимости установлены

### База данных не создается

1. Проверьте права доступа к папке проекта
2. Убедитесь, что путь к базе данных указан правильно в `DATABASE_PATH`
3. Проверьте логи на наличие ошибок создания таблиц

## Важные замечания

- **Не указывайте порт в коде** - Passenger автоматически управляет этим
- **Файл `passenger_wsgi.py` обязателен** - без него приложение не запустится
- **Переменная `application = app` обязательна** в `app.py` - она уже добавлена
- **Webhook URL должен быть HTTPS** - Telegram требует SSL сертификат
- **Аудио файлы** должны быть загружены в папку `audios/` с правильной структурой
